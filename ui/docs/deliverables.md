# Deliverables

Complete all three phases and commit your code via `git`, and useful project files before the presentation to a personal github to share for offline review after your presentation.

Leave the project ready to run so we can review and exercise the work together.

Update the [**SUBMISSION.md**](/submission) document with a section for each phase. For every phase, briefly record:

- What you delivered and what you chose to leave out.
- How hard each phase was and any challenges you faced.
- Important decisions, assumptions, and trade-offs.
- Tests or checks you ran, plus known gaps or next steps.
- Product ideas to explore or implement in the future.

## Present your work

Be ready to run the project and show the experience you built, then walk through the submission document alongside the relevant parts of your code. We will discuss your approach, decisions, and any trade-offs you made during the project.
