# Full-stack engineer technical assessment

Build a local secrets-scanning playground. Explore user needs, make thoughtful full-stack decisions, and reason through difficult edge cases. There is no single correct solution, and unfinished stretch goals are expected.

**Starter stack:** React + Vite UI; Rust + Axum API.

Use [**Playground**](/playground) to implement the scanner. [**API Docs**](/api-docs) shows the available server endpoints.
