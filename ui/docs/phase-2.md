Implement the core experience in this repository:

- Build the [Playground](/playground) UI using Vite.
- Implement a Rust API that accepts text and configuration and returns scan results.
- Make the frontend and API work together locally using the provided startup script.
- Include a small, clearly documented set of useful detection rules. Choose a reasonable approach and explain its trade-offs.
- Show useful results in the UI, including the location and type of each finding.
- Handle invalid input/configuration and API failures without losing the user's text.
- Add tests for the behavior you implement.

Keep the solution appropriately scoped. A reliable, understandable baseline is more valuable than a large number of unfinished features.
